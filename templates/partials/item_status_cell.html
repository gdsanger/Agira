{% comment %} Inline status editor for Item list views (#1249). One fragment for every item list — the django-tables2 tables render it through `ItemListColumnsMixin.render_status`, hand-written lists include it directly — so `/items/{status}/`, the project detail items tab and the nested lists all get the same markup, the same endpoint and the same error handling. Mail-free by construction: it posts to `item-list-status`, which only performs the workflow transition. The DetailView mail trigger / mail modal is not reachable here. Context: `item`, `status_choices` (from ItemStatus.choices), optional `status_error` and `status_saved`. {% endcomment %}
